Portfolio project: This model is an independent analytical exercise based on the transaction structure and forecast assumptions shown in the workbook. Forecast outputs are illustrative and are not investment advice.

Base-Case EPS Impact

The model projects the transaction to remain EPS-accretive across the forecast period, with estimated accretion of approximately 3.0% in 2024E, 2.3% in 2025E, and 1.8% in 2026E. The 2026E sensitivity analysis ranges from approximately 2.37% dilution to 5.95% accretion, depending on Pioneer earnings and realized synergies.

Key Modeling Logic

Share Issuance

New Exxon shares issued are calculated using Pioneer diluted shares and the transaction exchange ratio. The additional shares are added to ExxonMobil's standalone diluted share count to estimate pro forma shares.

Pro Forma Net Income

Pro forma net income combines ExxonMobil standalone net income, Pioneer standalone net income, and after-tax transaction synergies.

EPS Accretion / Dilution

The model compares pro forma combined EPS against ExxonMobil standalone EPS:

EPS Accretion / (Dilution) = Pro Forma EPS / Exxon Standalone EPS - 1

Sensitivity Analysis

The 2026E sensitivity table tests the effect of changes in:

Pioneer standalone net income

Pretax synergy realization

This shows the range of outcomes in which the acquisition becomes more accretive or potentially dilutive.
